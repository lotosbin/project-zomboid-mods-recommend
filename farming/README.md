# 农业/生物类模组

这些模组专注于增强Project Zomboid的农业系统和生物资源管理，为玩家提供更丰富的食物来源和养殖体验，让末日生存更加多样化。

## 农业/生物类模组特点

这类模组通常具有以下特点：

1. **资源扩展**：添加新的种植作物、养殖动物或昆虫系统
2. **生产链完善**：提供从生产到加工的完整生产链
3. **生存多样化**：增加食物获取的多样性和稳定性
4. **生态互动**：添加生物之间的互动关系和环境影响因素
5. **长期发展**：提供可持续的长期生存资源获取方式

**模组详情**

由Rocco创作的全新蜜蜂养殖系统模组，引入了功能性的蜂箱结构、蜂蜜食品、医疗物品等丰富的蜜蜂养殖体验。

#### B42.13补丁详情

由Tchernobill创作的兼容性补丁，为ShelterHold : Beehive提供Build 42.13版本的兼容性支持。

- **功能**：修复原版模组在B42.13版本中出现的错误和兼容性问题
- **兼容性**：专门为Build 42.13设计，与原版模组一起使用
- **测试状态**：作者表示为"barely tested"，如有问题请在官方PZ Discord报告并提供控制台日志
- **注意事项**：主要针对单人模式，多人游戏兼容性可能不同

**蜜蜂系统**：
- **蜜蜂种类**：三种蜜蜂 - **蜜蜂**、**大黄蜂**和**僵尸蜜蜂**（是的，如果世界已有僵尸，为什么不能有僵尸化的蜜蜂呢？）
- **环境因素**：温度、天气、一天中的时间以及蜂箱是否在室外都会影响蜜蜂外出采集花蜜
- **框架影响**：添加更多框架将提高蜂蜜生产效率
- **农业影响**：当蜂箱有活跃蜜蜂时，附近作物会获得少量生长速度加成
- **注意**：取出蜜蜂或框架可能会被蜇一下或被刮伤，但不会致命，甚至不需要绷带，它会自行快速愈合

**蜂蜜提取器**：
- 用于从蜂箱框架中提取蜂蜜
- 只能在蜂箱显示准备好收获时才能提取蜂蜜
- 需要持续点击提取器按钮来填充进度条并收集蜂蜜
- 提取器有小几率损坏框架

**新食物、物品和诱饵蜂箱**：
- **食物**：数十种新的蜂蜜基食品 - 比常规食品含有更高的热量和碳水化合物
- **医疗**：两种新的治疗物品 - **蜂蜜绷带**和**蜂蜜贴片**，比标准绷带保持干净的时间更长
- **武器维护**：使用**蜂蜡**有小几率恢复武器的修复次数之一
- **采集**：在森林区域搜索时可以轻松找到蜜蜂和野生蜂箱
- **诱饵蜂箱**：放置诱饵蜂箱，添加蜂蜜、蜂蜡或其他甜食，可能会吸引野生蜂箱。分解它们可以获得蜂蜜、蜂蜡甚至活蜜蜂

**防护措施**：
- 穿着防化服或Spiffo吉祥物服装可以防止被蜇
- 或者，在蜜蜂睡觉时工作可能是一个聪明的主意

**依赖关系**：
- 需要[B42]NeatUI Framework

**模组详情**

由飞奔创作的中文风味模组，带来了丰富的中国传统美食和酿酒系统，为游戏增添了独特的文化元素。

**新增内容**：
- **十二生肖·兔符咒**：增加人物慢跑移速35%（限时1天）
- **全新的酿酒系统**：
  - 新增高粱作物种植
  - 新增水稻种植，可获得大米
  - 共酿造14种水果果酒、8种白酒酿造、7种啤酒酿造
  - 增加酵母、酒曲等的相关工艺制作
- **新增人物特性**：酿酒师（酿酒等级+2）
- **制糖工艺**：
  - 先用足够数量的甘蔗（甘蔗可在水果店搜到直接种植）
  - 通过压榨机榨取甘蔗汁
  - 过滤器过滤甘蔗汁
  - 锅具熬煮甘蔗汁

**使用方法**：
1. 订阅"[B42]舌尖上的中国"模组
2. 确保选择与您游戏版本兼容的版本（42.13.1版本或42.12版本）
3. 注意不可同时启用两个版本，会导致游戏崩溃
4. 在游戏中寻找甘蔗、高粱、水稻种子和酵母等原料
5. 开始你的中式美食和酿酒之旅
