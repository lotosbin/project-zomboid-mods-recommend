

```# 健康系统类模组

本分类包含增强Project Zomboid健康和疾病系统的模组，提供更真实、更深入的健康管理体验，增加游戏的挑战性和沉浸感。

## 模组列表

### 1. [B42.13]Realistic Disease Mod

- **作者**：KingYufka
- **功能**：扩展Project Zomboid的疾病系统，增加基于真实医学原因、症状和环境因素的详细疾病机制
- **特点**：
  - 基于真实医学原因、症状和环境因素的疾病系统
  - 更深度的疾病机制，增加危险性和沉浸感
  - 每种疾病都有详细的医学背景和症状表现
  - 疾病不再是短暂的负面状态，而是需要认真对待的健康威胁
- **疾病类型**：
  - 环境因素引起的疾病（温度、湿度等）
  - 食物中毒和水源污染相关疾病
  - 伤口感染和并发症
  - 心理健康问题
- **兼容性**：✅ B42.13兼容
- **更新状态**：持续更新
- **安装建议**：适合寻求更高难度和真实感的玩家
- **注意事项**：
  - 显著增加游戏难度，新手玩家请谨慎使用
  - 需要更仔细的健康管理和资源规划
  - 建议与其他健康相关模组（如医疗扩展）配合使用

## 健康系统类模组特点

1. **真实医学基础**：疾病机制基于真实医学知识，增加游戏的教育价值
2. **深度机制**：不再是简单的状态条，而是复杂的健康系统
3. **环境交互**：健康状态与环境因素密切相关，增加游戏策略性
4. **长期影响**：疾病和治疗对长期生存有重要影响

## 使用建议

1. **加载顺序**：建议在基础游戏功能模组之后、界面增强模组之前加载
2. **难度调整**：首次使用建议降低其他游戏难度，适应新的健康系统
3. **资源准备**：游戏开始时优先准备医疗资源，应对更复杂的健康挑战
4. **学习曲线**：花时间了解各种疾病的成因和治疗方法，提高生存率

## 兼容性注意事项

1. **医疗模组交互**：可能与其他增强医疗系统的模组产生冲突
2. **难度影响**：会显著增加游戏难度，可能与其他难度调整模组产生叠加效果
3. **多人游戏**：确保所有玩家安装相同的健康模组，避免同步问题

## 新手提示

1. **常见疾病**：优先了解最常见疾病的成因和预防方法
2. **医疗资源**：尽早囤积抗生素、消毒剂等关键医疗用品
3. **预防为主**：注意保持清洁、避免接触污染源、确保食物安全
4. **症状识别**：学习识别不同疾病的早期症状，及时治疗

## 未来计划

- 添加更多疾病类型和病理机制
- 扩展医疗选项和治疗方法
- 添加医疗检查工具和诊断设备
- 优化健康状态显示界面
- 增加NPC健康互动和治疗
