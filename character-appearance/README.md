# 角色和外观类模组

这些模组专注于改变Project Zomboid中角色的外观和体型，提供更多样化的角色定制选项，让玩家能够创建更符合个人喜好或游戏风格的角色形象。

## 角色和外观类模组特点

这类模组通常具有以下特点：

1. **外观定制**：提供更丰富的角色外观选项和自定义能力
2. **体型变化**：改变角色的基本体型和身体特征
3. **视觉多样性**：增加游戏中的视觉多样性，减少角色外观的重复感
4. **个性化表达**：允许玩家通过外观表达个人风格和偏好
5. **沉浸感提升**：通过更符合玩家期望的角色外观增强游戏沉浸感

**模组详情**

由布偶旧猫小号创作的女性角色体型模组，为游戏中的女性角色提供了不同的身体模型选项，让玩家能够创建更多样化的女性角色形象。

- **核心功能**：
  - 提供女性角色的新身体模型
  - 改变角色的基础体型和外观
  - 兼容Build 42.13.1版本
  - 包含多个版本选项（如VSGirlBodyL_v3.0等）

- **安装方法**：
  1. 订阅模组
  2. 在主界面（退出游戏页面）启用模组
  3. 退出游戏并重新进入以启动模组
  4. 开始游戏体验新的角色外观

- **使用注意事项**：
  - 需要在游戏主界面（而非模组界面）启用模组
  - 安装后需要重启游戏以完全加载模组内容
  - 可能与服装模组产生交互影响
  - 在多人游戏中，其他玩家也需安装相同模组才能看到效果

- **版本说明**：
  - v3.1版本针对Build 42.13.1优化
  - 可能包含多个子版本选项，适应不同需求
  - 持续更新以保持与最新游戏版本的兼容性

- **与其他模组的兼容性**：
  - 大多数情况下与服装模组兼容
  - 可能需要特定的适配补丁与某些服装模组配合使用
  - 不影响游戏核心机制，仅改变视觉外观

## 角色外观定制的重要性

在Project Zomboid这样的角色扮演游戏中，角色外观对玩家体验有着微妙但重要的影响：

1. **情感连接**：能够创建符合个人喜好的角色外观有助于增强玩家与角色的情感连接
2. **身份认同**：角色外观是玩家在游戏世界中表达自我和身份的一种方式
3. **沉浸感**：更符合玩家期望的角色外观有助于提高游戏沉浸感
4. **社交识别**：在多人游戏中，独特的外观有助于快速识别不同玩家的角色
5. **长期兴趣**：丰富的外观选择可以保持玩家对角色创建和长期游玩的兴趣

## 安装和注意事项

1. **多人游戏一致性**：在多人游戏中，确保所有玩家使用相同版本的外观模组
2. **与其他模组交互**：注意外观模组与服装、装备类模组的交互影响
3. **存档兼容性**：某些外观更改可能在现有存档中引起问题，建议在新游戏中使用
4. **性能影响**：高质量的外观模组可能对游戏性能有轻微影响
