# 界面增强类模组

这些模组专注于改进Project Zomboid的用户界面(UI)和交互体验，通过重新设计或添加新功能使游戏界面更加直观、高效和美观。

## 界面增强类模组特点

这类模组通常具有以下特点：

1. **界面重设计**：提供更清晰、更直观的界面布局和视觉元素
2. **交互优化**：简化常见操作，减少点击次数和界面切换
3. **视觉效果**：改进UI元素的外观和动画效果
4. **操作便捷性**：添加快捷功能键、径向菜单等交互方式
5. **定制选项**：允许玩家自定义界面布局和显示选项
6. **控制器支持**：增强手柄和Steam Deck的使用体验

### [B42]Clean HotBar v1.8 整洁快捷栏

| 模组名称 | Workshop ID | 链接 | Mod ID | 版本 | 状态 |
|---------|------------|------|--------|------|------|
| [B42]Clean HotBar v1.8 | 3461263912 | [链接](https://steamcommunity.com/sharedfiles/filedetails/?id=3461263912) | CleanHotBar | v1.8 | ✅ 兼容B42.13 |

**模组详情**

由Rocco创作的快捷栏UI改进模组，重新设计了快捷栏界面，提供更直观的装备状态显示和更清晰的视觉效果。

- **主要功能**：
  - **B42兼容状态显示**：完全整合B42新增的武器/物品状态显示
    - 武器头部状态：当武器有头部状态数据时，在插槽上方显示状态条
    - 武器锋利度：显示两个值 - 白色表示实际锋利度，棕色表示最大锋利度
    - 开关物品：为手电筒等可开关物品提供清晰的ON/OFF指示器
    - 弹药计数器：在火器插槽上方显示弹药数量
  - **手持装备显示改进**：手持装备也可以显示更详细的信息
  - **B42液体系统集成**：使用颜色编码条可视化B42液体系统
  - **动画效果**：包括耐久度抖动、闪烁效果和液体流动动画
  - **耐久度警告**：当装备武器的耐久度下降时，在角色头顶显示警告（可在设置中禁用）

- **定制设置**：
  - 为硬核玩家禁用所有状态显示
  - 调整状态条高度
  - 启用工具提示（默认关闭）以在悬停时显示物品详细信息
  - 缩放快捷栏大小
  - 切换角色上方武器耐久度警告动画

- **兼容性**：
  - 与"Reorder the Hotbar"兼容 - 最佳加载方式是将Clean HotBar放在加载顺序底部，让其他模组先加载
  - 可能与在快捷栏上显示状态指示器的任何模组冲突
  - 如遇到错误或将模组无法按预期工作，请尝试将Clean HotBar放在模组加载顺序的底部

- **注意事项**：
  - 当前仅实现了手持装备槽的基本状态显示
  - 欢迎提供创意建议！

## 模组使用指南

### CleanUI 界面优化（仅原版）

1. 订阅原版"[B42]CleanUI V2.2"模组 (ID: 3437629766)
2. 启动Project Zomboid
3. 在模组列表中启用该模组
4. 根据个人需求，使用ModOptions界面调整CleanUI设置

**注意**：B42.13兼容性补丁当前会导致游戏崩溃，建议等待更新。

### [B42]Clean HotBar v1.8

1. 订阅"[B42]Clean HotBar v1.8"模组 (ID: 3461263912)
2. 启动Project Zomboid
3. 在模组列表中启用该模组（建议放在加载顺序底部）
4. 在游戏中根据个人喜好调整快捷栏设置
5. 使用设置面板（悬停在快捷栏上时出现）进行自定义

**注意**：如遇到其他UI模组冲突，请尝试调整模组加载顺序。

### Smart Radial Menu

1. 订阅"Smart Radial Menu"模组 (ID: 3494108029)
2. 启动Project Zomboid
3. 在模组列表中启用该模组
4. 在游戏中尝试右键（或使用控制器键）打开径向菜单
5. 根据需要调整模组选项（如果有）

### Neat系列界面模组使用指南

#### [B42]Neat Crafting V1.5 及 B42.13补丁

1. 订阅原版"[B42]Neat Crafting V1.5"模组 (ID: 3502080466)
2. 订阅"Neat Crafting Patch for B42.13"补丁 (ID: 3623287625)
3. 启动Project Zomboid
4. 在模组列表中启用这两个模组（确保加载顺序正确：原版->补丁->其他）
5. 在游戏中使用重新设计的制作界面

#### [B42]Neat Building + More Buildings V1.4

1. 订阅"[B42]Neat Building + More Buildings V1.4"模组 (ID: 3536052310)
2. 启动Project Zomboid
3. 在模组列表中启用该模组
4. 在游戏中使用双击建造功能
5. 如需B42.13支持，确保也加载Neat Crafting Patch for B42.13 (ID: 3623287625)

#### [B42]Project Cook (New)V1.0

1. 订阅"[B42]Project Cook (New)V1.0"模组 (ID: 3490188370)
2. 确保已订阅"[B42]NeatUI Framework"模组
3. 启动Project Zomboid
4. 在模组列表中启用这些模组
5. 在游戏中通过悬停制作按钮或右键食物打开烹饪面板

#### [B42]ModernStatus V2.0

1. 订阅"[B42]ModernStatus V2.0"模组 (ID: 3451167732)
2. 启动Project Zomboid
3. 在模组列表中启用该模组
4. 在游戏中右键状态指示器进行自定义设置
5. 如需重置位置，删除保存文件夹中的ModernStatusConfig.lua文件
