# 界面增强类模组

这些模组专注于改进Project Zomboid的用户界面(UI)和交互体验，通过重新设计或添加新功能使游戏界面更加直观、高效和美观。

## 界面增强类模组特点

这类模组通常具有以下特点：

1. **界面重设计**：提供更清晰、更直观的界面布局和视觉元素
2. **交互优化**：简化常见操作，减少点击次数和界面切换
3. **视觉效果**：改进UI元素的外观和动画效果
4. **操作便捷性**：添加快捷功能键、径向菜单等交互方式
5. **定制选项**：允许玩家自定义界面布局和显示选项
6. **控制器支持**：增强手柄和Steam Deck的使用体验

| CleanUI Patch for B42.13 | 3623352001 | [链接](https://steamcommunity.com/sharedfiles/filedetails/?id=3623352001) | CleanUI_B42_13 | - | ❌ 会导致崩溃 |

**模组详情**

由Rocco创作的完全streamlined UI布局模组，提供更简洁、更高效的库存管理体验。

- **主要功能**：
  - 将容器按钮移至左侧，使操作更自然
  - 所有功能移至可折叠面板
  - "Transfer All"和"Take All"动作集成到容量显示框
  - 用折叠图标替换物品图标，使组织更清晰
  - 重新设计所有UI纹理，采用极简边框和高透明度
  - 自动截断物品/类型名称，防止重叠

- **高级功能**：
  - 容器重排序功能
  - 搜索功能
  - 分类转移
  - 排序功能
  - 折叠/展开所有物品
  - 隐藏已装备物品

**注意**：B42.13兼容性补丁当前会导致游戏崩溃，建议等待作者更新后再使用。

### Smart Radial Menu 智能径向菜单

| 模组名称 | Workshop ID | 链接 | Mod ID | 版本 | 状态 |
|---------|------------|------|--------|------|------|
| Smart Radial Menu | 3494108029 | [链接](https://steamcommunity.com/sharedfiles/filedetails/?id=3494108029) | SmartRadialMenu | 1.6 | ✅ 兼容B42.13 |

**模组详情**

由Phoenix创作的智能径向菜单，提供快速访问常用物品操作的功能，特别支持控制器和Steam Deck。

- **主要功能**：
  - 动态径向菜单：扫描库存和附近物品，显示相关选项
  - 控制器支持：专为鼠标+键盘、游戏手柄和Steam Deck导航设计
  - 物品过滤：排除变质、危险和有毒物品
  - 学习制作配方：显示可以从物品研究的配方
  - 服装操作：添加穿戴、脱下和检查服装的选项
  - 子菜单：为配料、地图和装备的服装添加子菜单

- **兼容性**：
  - 兼容TidyUp Meister、Picking Meister、Drink Smart和Better Sorting
  - 可能与organizedCategories不兼容

## 模组使用指南

### CleanUI 界面优化（仅原版）

1. 订阅原版"[B42]CleanUI V2.2"模组 (ID: 3437629766)
2. 启动Project Zomboid
3. 在模组列表中启用该模组
4. 根据个人需求，使用ModOptions界面调整CleanUI设置

**注意**：B42.13兼容性补丁当前会导致游戏崩溃，建议等待更新。

### Smart Radial Menu

1. 订阅"Smart Radial Menu"模组 (ID: 3494108029)
2. 启动Project Zomboid
3. 在模组列表中启用该模组
4. 在游戏中尝试右键（或使用控制器键）打开径向菜单
5. 根据需要调整模组选项（如果有）
