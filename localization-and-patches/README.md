  - 帮助玩家做出更明智的角色创建选择

- **内容特点**：
  - 详细解释每个职业的优缺点
  - 说明特性数值如何影响游戏机制
  - 提供策略建议和搭配推荐
  - 包含游戏机制背后的逻辑解释
  - 为新手玩家提供入门指导

- **界面改进**：
  - 在角色创建界面添加详细描述
  - 保持原版界面风格的同时增加信息量
  - 优化文本排版，提高可读性
  - 不影响游戏性能或运行速度

- **兼容性**：
  - 专为Build 42.13设计
  - 与大多数游戏模组兼容
  - 不会影响游戏平衡，仅提供信息
  - 支持多人游戏环境

- **使用价值**：
  - 降低新手入门门槛
  - 减少试错成本
  - 提高角色创建的满意度
  - 增强游戏整体体验

- **安装建议**：
  - 适合所有玩家，特别是新手
  - 建议在角色创建前安装
  - 可以随时停用，不影响已有角色
  - 与其他教学类模组搭配使用效果更佳

## 本地化和修复类模组特点

这类模组通常具有以下特点：

1. **语言本地化**：提供游戏中未包含的语言翻译，特别是中文等多语言支持
2. **兼容性修复**：为主流模组提供新游戏版本的兼容性补丁
3. **错误修复**：修复游戏或其他模组中的已知问题和错误
4. **UI改进**：优化用户界面元素，提高可读性和易用性
5. **多版本支持**：同时支持多个游戏版本，满足不同玩家的需求
