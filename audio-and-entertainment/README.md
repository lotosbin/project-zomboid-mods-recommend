## 音频和娱乐类模组特点

1. **多样化内容**：提供不同风格的音乐电台和点唱机，满足不同玩家需求
2. **本地化支持**：包含中文音乐内容，适合中文玩家
3. **多人游戏兼容**：支持在多人游戏中使用，不会影响游戏同步
4. **轻量级设计**：模组体积小，性能影响最小
5. **版本专精**：针对不同游戏版本提供专门的模组，确保最佳兼容性

## 使用建议

1. **加载顺序**：建议在游戏功能模组之后加载，避免与音频相关的模组冲突
2. **网络要求**：使用音乐电台功能需要稳定的网络连接
3. **兼容性**：与其他音频模组可能存在兼容性问题，建议逐一测试
4. **设置调整**：可在游戏设置中调整音频音量，平衡游戏音效和音乐
