

```# 音频和娱乐类模组

本分类包含增强Project Zomboid音频体验和娱乐功能的模组，为游戏添加更多沉浸式声音效果和音乐内容。

## 模组列表

### 1. True Music Radio B42 MP+

- **作者**：norby007
- **Workshop ID**：待补充
- **功能**：添加音乐电台，包含三个默认电台，每个电台播放不同的播放列表
- **默认电台**：
  - 92FM：从全局列表或Terminal A播放列表播放
  - 92.2FM：从全局列表或Terminal B播放列表播放
  - 92.4FM：从全局列表或Terminal C播放列表播放
- **兼容性**：✅ B42多人游戏兼容
- **更新状态**：持续更新
- **安装建议**：适合希望在游戏中享受自定义音乐内容的玩家
- **注意事项**：需要网络连接以访问音乐内容

### 2. True Music CN

- **作者**：To游离
- **Workshop ID**：2957823594
- **Mod ID**：gouku
- **功能**：提供中文音乐内容，是True Music的自用音乐模组
- **兼容性**：✅ B42兼容
- **更新状态**：个人维护
- **安装建议**：适合中文玩家，可作为True Music Radio的补充
- **注意事项**：包含中文音乐内容，适合喜欢中文音乐的玩家

## 音频和娱乐类模组特点

1. **多样化内容**：提供不同风格的音乐电台，满足不同玩家需求
2. **本地化支持**：包含中文音乐内容，适合中文玩家
3. **多人游戏兼容**：支持在多人游戏中使用，不会影响游戏同步
4. **轻量级设计**：模组体积小，性能影响最小

## 使用建议

1. **加载顺序**：建议在游戏功能模组之后加载，避免与音频相关的模组冲突
2. **网络要求**：使用音乐电台功能需要稳定的网络连接
3. **兼容性**：与其他音频模组可能存在兼容性问题，建议逐一测试
4. **设置调整**：可在游戏设置中调整音频音量，平衡游戏音效和音乐
