

```# 游戏机制修复类模组

本分类包含修复Project Zomboid游戏机制问题的模组，解决原版游戏中的错误和不便之处，提供更流畅的游戏体验。基于bin^2的B42.13合集，包含9个游戏机制修复类模组，涵盖多人烹饪修复、衣物撕裂、多人游戏修复、定时动作修复、知识传授等方面。

## 合集中的游戏机制修复模组

根据bin^2的B42.13合集，包含以下游戏机制修复类模组：

- [b42.13.1]Multiplayer Crafting Fixes - 修复多人游戏中制作物品选择被忽略的问题
- DryingRacksFixed B42 MP - 修复B42多人游戏中干燥架机制的问题
- [b42.13.1] Multiplayer Timed Actions Fix [Beta] - 修复多人游戏中的定时动作问题
- [B42 MP] Teach Knowledge - 允许技能熟练的生存者向他人传授知识
- CookingSync - Multiplayer Cooking Fix [v5.0] - 修复多人游戏中的烹饪同步错误
- Rip All Clothes - 修复衣物撕裂机制

## 🔄 多人游戏特别说明

多个多人游戏修复模组需要服务器特定的配置才能正常工作。请在服务器配置文件(.ini)中设置：

```
DoLuaChecksum=false
```

此设置允许客户端和服务器之间进行更灵活的脚本同步，是许多多人游戏修复模组正常工作的必要条件。

### 常见多人游戏问题

1. **制作系统**：制作物品选择被忽略，客户端与服务器状态不同步
2. **烹饪同步**：原料不显示在锅/平底锅中，烹饪状态视觉不更新
3. **干燥架机制**：皮革和植物干燥过程同步问题
4. **定时动作**：动作持续时间、内部状态或项目引用不一致

## 游戏机制修复类模组特点

1. **问题导向**：专门解决原版游戏中的特定问题和错误
2. **多人游戏优化**：特别关注多人游戏环境下的同步和兼容性问题，提供针对性的多人游戏修复
3. **轻量级设计**：专注于功能修复，不添加不必要的复杂内容
4. **持续维护**：作者积极响应问题和反馈，及时更新
5. **服务器需求**：多人游戏修复模组通常需要特定的服务器配置（如DoLuaChecksum=false）
6. **功能增强**：部分模组不仅修复问题，还增加了实用功能（如附件扩展、隐藏携带等）
7. **社区贡献**：部分模组由社区成员接手维护，继续为玩家提供支持

## 使用建议

1. **加载顺序**：建议在主要功能模组之后加载，确保修复效果正确应用
2. **多人游戏**：确保所有玩家安装相同的修复模组，避免同步问题
3. **配置调整**：根据个人游戏风格调整模组设置，优化体验
4. **问题反馈**：遇到问题时应及时向作者反馈，帮助改进模组
5. **多人专用模组**：部分修复模组仅适用于多人游戏，单人游戏无需安装，可能引起不必要的问题
6. **服务器配置**：多人游戏修复模组通常需要服务器端特定的配置，请仔细阅读模组说明
7. **功能增强模组**：对于添加新功能的模组（如附件扩展、隐藏携带），建议在测试环境中先行体验
8. **兼容性补丁**：某些模组需要特定的兼容性补丁，确保所有相关补丁都已安装

## 兼容性注意事项

1. **与其他模组的交互**：可能与其他修改相同游戏机制的模组冲突
2. **版本更新**：游戏版本更新后，检查修复模组是否需要更新
3. **存档兼容**：大多数修复模组与现有存档兼容，但建议先备份
4. **多人游戏要求**：多人游戏修复模组通常需要所有玩家和服务器安装相同版本
5. **专用性与通用性**：区分多人游戏专用修复和通用修复，避免在单人游戏中安装不需要的模组
6. **功能增强影响**：增强类模组（如附件扩展、隐藏携带）可能会影响游戏平衡，多人游戏需谨慎使用
7. **依赖关系**：某些修复模组可能依赖特定框架
