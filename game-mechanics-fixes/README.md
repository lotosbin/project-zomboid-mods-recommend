

```# 游戏机制修复类模组

本分类包含修复Project Zomboid游戏机制问题的模组，解决原版游戏中的错误和不便之处，提供更流畅的游戏体验。

## 模组列表

### 1. CookingSync - Multiplayer Cooking Fix [v5.0]

- **作者**：SENS_DEP
- **Workshop ID**：3773820803
- **功能**：修复Build 42多人游戏中的烹饪同步错误
- **解决的问题**：
  - 原料通过右键菜单添加时不显示在锅/平底锅中
  - 烹饪过程中食物物品视觉上不更新
  - 主机和客户端之间烹饪状态不同步
- **支持的设备**：炉灶、烤箱、微波炉、烧烤架等烹饪设备
- **兼容性**：✅ B42兼容
- **多人游戏**：✅ 完全支持
- **更新状态**：v5.0（最新稳定版）
- **安装建议**：多人游戏必备，特别是对于经常一起烹饪的团队
- **注意事项**：
  - 需要所有玩家安装才能在多人游戏中正常工作
  - 可能需要重启游戏以完全生效

### 2. Rip All Clothes

- **作者**：Notone
- **Workshop ID**：3782616137
- **功能**：允许撕下指定范围内的所有衣物
- **特性**：
  - 可配置撕扯范围（在模组选项中设置）
  - 支持自动转移选项（在模组选项中设置）
  - 支持从多种来源撕扯衣物：货架、衣架、人体模型等
  - B42和多人游戏支持
- **使用方法**：
  1. 在模组选项中配置撕扯范围
  2. 启用自动转移（可选）
  3. 在游戏中使用相应动作撕扯衣物
- **兼容性**：✅ B42多人游戏兼容
- **更新状态**：持续更新（update3版本）
- **安装建议**：适合需要大量布料的玩家，节省时间
- **注意事项**：
  - 可能会产生大量噪音，吸引僵尸
  - 在多人游戏中需要同步，建议所有玩家安装

## 游戏机制修复类模组特点

1. **问题导向**：专门解决原版游戏中的特定问题和错误
2. **多人游戏优化**：特别关注多人游戏环境下的同步和兼容性问题
3. **轻量级设计**：专注于功能修复，不添加不必要的复杂内容
4. **持续维护**：作者积极响应问题和反馈，及时更新

## 使用建议

1. **加载顺序**：建议在主要功能模组之后加载，确保修复效果正确应用
2. **多人游戏**：确保所有玩家安装相同的修复模组，避免同步问题
3. **配置调整**：根据个人游戏风格调整模组设置，优化体验
4. **问题反馈**：遇到问题应及时向作者反馈，帮助改进模组

## 兼容性注意事项

1. **与其他模组的交互**：可能与其他修改相同游戏机制的模组冲突
2. **版本更新**：游戏版本更新后，检查修复模组是否需要更新
3. **存档兼容**：大多数修复模组与现有存档兼容，但建议先备份
