# 项目模组合集

## bin^2的B42.13合集

本项目的核心参考模组合集为 **[bin^2的B42.13合集](https://steamcommunity.com/sharedfiles/filedetails/?id=3624259825)**，这是一个精心挑选的B42.13兼容模组集合，为玩家提供全面的游戏体验增强。

### 合集信息

- **适用版本**：Project Zomboid Build 42.13/42.13.1
- **最后更新**：2025年1月11日（当前检查：2026年1月28日）
- **订阅量**：持续增长中

### 模组加载顺序建议

1. 框架类模组（如NeatUI Framework）
2. 主要功能模组（如Neat Crafting、Neat Building）
3. 附加组件（如XP Display）
4. 兼容性补丁（已归类到对应的主模组中，与主模组一同加载）
5. 注意：[OBSOLETE] CleanUI Patch for B42.13已标记为过时，不应使用

### 使用合集的优势

1. **一站式解决方案**：一次性订阅所有兼容性良好的模组
2. **兼容性保证**：所有模组已验证在B42.13.1中兼容（部分需要补丁）
3. **精心挑选**：只包含高质量、无冲突的模组
4. **持续更新**：合集作者会及时替换或更新不兼容的模组
5. **兼容性保证**：包含必要的补丁确保B42.13.1兼容性
6. **多样性**：包含界面、本地化、游戏机制、多人游戏、车辆、建筑等多种类型的模组
7. **功能丰富**：涵盖游戏体验的各个方面，从基础UI改进到高级游戏机制
8. **分类明确**：修复类模组与原模组归类在一起，便于管理和使用

### 如何使用

1. 点击[这里访问合集页面](https://steamcommunity.com/sharedfiles/filedetails/?id=3624259825)
2. 点击"Subscribe to all"按钮订阅所有模组
3. 启动Project Zomboid
4. 在模组列表中确保所有模组已启用
5. 根据需要调整模组加载顺序（参考上表建议）
