### 如何使用该合集

1. 点击合集链接访问Steam Workshop页面
2. 点击"Subscribe to all"按钮订阅所有模组
3. 启动Project Zomboid
4. 在模组列表中确保所有模组已启用
5. 根据需要调整模组加载顺序
