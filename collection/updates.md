# 模组合集更新说明

## bin^2的B42.13合集更新日志

本文档记录了我们的核心参考模组合集 **[bin^2的B42.13合集](https://steamcommunity.com/sharedfiles/filedetails/?id=3624259825)** 的更新情况，包括新增模组、版本更新和兼容性变化。

### 最新更新检查时间
2025年12月20日

### 当前合集信息
- **作者**：bin^2
- **模组数量**：27个（从之前的23个增加了4个）
- **适用版本**：Project Zomboid Build 42.13
- **最后更新**：2023年12月18日

## 新增模组（自上次检查）

### 1. Clean UI Menu Support
- **作者**：Phoenix
- **功能**：为CleanUI按钮添加上下文菜单支持，提高与Steam Deck和控制器的兼容性
- **状态**：✅ 兼容B42.13
- **分类**：UI修复和改进

### 2. Sidebar Controller Support
- **作者**：Phoenix
- **功能**：为管理装备和背包的侧边栏添加手柄支持，按Select按钮可打开上下文菜单
- **状态**：✅ 兼容B42.13
- **分类**：控制器支持

### 3. Neat Ingredients List
- **作者**：Phoenix
- **功能**：将重复的原料分组为单个选项，食物原料按使用次数排序，香料按稀有度排序
- **状态**：✅ 兼容B42.13
- **分类**：UI改进

### 4. Consolidate All Fix (B42)
- **作者**：Phoenix
- **功能**：修复Build 42中上下文菜单的"Consolidate all"按钮问题
- **状态**：✅ 兼容B42.13
- **分类**：错误修复
- **注意**：一旦原版游戏修复此问题，该模组将被移除

## 版本更新模组

- **更新类型**：版本标记修正
- **说明**：确认这是B42.12版本，B42.13用户应使用[B42]ModernStatus V2.0

- 大多数模组已确认与B42.13兼容

## 下次更新计划

### 定期检查
建议每月检查一次模组合集的更新，特别关注：
1. 新增模组
2. 版本更新
3. 兼容性变化
4. 已知问题修复

### 更新检查方法
1. 访问合集页面：[bin^2的B42.13合集](https://steamcommunity.com/sharedfiles/filedetails/?id=3624259825)
2. 检查模组数量是否变化
3. 查看模组列表是否有新增或移除的项
4. 检查各模组的最后更新日期
5. 更新本更新日志文档

### 文档更新流程
1. 将新增模组添加到适当的分类中
2. 更新模组版本和兼容性状态
3. 在更新日志中记录变化
4. 更新主README.md中的模组数量
5. 更新collection/README.md中的模组列表

## 注意事项

1. **模组加载顺序**：某些补丁模组需要与原版模组一起使用，并确保正确的加载顺序
2. **多人游戏兼容性**：部分模组可能仅适用于单人游戏，多人游戏兼容性可能不同
3. **定期备份**：建议在添加新模组或更新现有模组前备份存档
4. **问题排查**：如遇到问题，先尝试禁用最近添加或更新的模组

## 反馈和贡献

如果您发现合集中有新的更新，或者在我们的文档中发现了过时的信息，请通过以下方式联系我们：

1. 在GitHub仓库中创建issue
2. 提供详细的模组信息（名称、ID、更新内容）
3. 说明遇到的任何兼容性问题
