## 兼容性说明

### 需要补丁的模组
| 模组 | 补丁 |
|------|------|
| Known And Collected | Known and Collected 42.13+ compatibility patch |
| Manage 42.13 Containers | Manage Containers+ compatibility patch |
| Read While Walking | Simple Read While Walking 42.13+ compatibility patch |

### 已损坏/过时的模组
- [OBSOLETE] CleanUI Patch for B42.13 - 已过时，会导致崩溃
- Neat Crafting V1.5 - 已停止更新，需要替代方案
- Neat Building V1.4 - 已停止更新，需要替代方案

### 多人游戏设置
多个多人游戏修复模组需要服务器设置 `DoLuaChecksum=false`

### 使用合集的优势
1. **一站式解决方案**：一次性订阅所有兼容性良好的模组
2. **兼容性保证**：所有模组已验证在B42.13.1中兼容（部分需要补丁）
3. **精心挑选**：只包含高质量、无冲突的模组
4. **持续更新**：合集作者会及时替换或更新不兼容的模组
5. **多样性**：包含界面、本地化、游戏机制、多人游戏、车辆、建筑等多种类型的模组
6. **功能丰富**：涵盖游戏体验的各个方面，从基础UI改进到高级游戏机制
7. **分类明确**：修复类模组与原模组归类在一起，便于管理和使用

## 注意事项

1. **模组加载顺序**：
   - 框架类模组（如NeatUI Framework）
   - 主要功能模组（如Neat Crafting、Neat Building）
   - 附加组件（如XP Display）
   - 兼容性补丁（已归类到对应的主模组中，与主模组一同加载）
   - 注意：[OBSOLETE] CleanUI Patch for B42.13已标记为过时，不应使用
2. **定期备份**：建议在添加新模组前备份存档
3. **兼容性测试**：新模组建议先在测试存档中验证
4. **B42.14.1兼容性**：所有模组已确认与Build 42.14.1兼容
