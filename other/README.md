# 其他类模组

这些模组不属于特定类别，但为Project Zomboid提供了各种有用的功能和改进。

## errorMagnifier

- **作者**：Chuckleberry Finn
- **功能**：发生错误时创建一个按钮，使错误报告对不太熟悉技术的玩家更加清晰和方便
- **状态**：✅ 兼容B42.13
- **分类**：错误报告/辅助工具
- **Workshop ID**：待补充

## Combat Text (B40+B41+B42)

- **作者**：Rezistor
- **功能**：在战斗中显示伤害数字和战斗信息，增强战斗体验的直观性
- **状态**：✅ 兼容B42.13
- **分类**：战斗界面/视觉效果
- **Workshop ID**：待补充
- **特点**：
  - 显示造成的伤害数值
  - 提供战斗反馈信息
  - 支持多人游戏
  - 可自定义显示选项

## 新增其他类模组（2025年12月26日更新）

### Random Zombies 随机僵尸

| 模组名称 | Workshop ID | 链接 | Mod ID | 版本 | 状态 |
|---------|------------|------|--------|------|------|
| Random Zombies | 待补充 | [链接待补充] | RandomZombies | - | ✅ 兼容B42.0.2和B41.76 |

**模组详情**

由belette创作的僵尸定制模组，允许玩家自定义游戏中各种类型僵尸的出现数量，为游戏提供更多的挑战性和变化。

- **核心功能**：
  - 自定义每种类型僵尸的出现比例
  - 支持爬行者、短跑者、智能者、强壮者等多种类型
  - 同时支持Build 42.0.2和Build 41.76版本
  - 兼容单人游戏和多人游戏

- **自定义选项**：
  - 调整普通僵尸数量
  - 自定义特殊僵尸类型出现率
  - 可能支持难度等级和游戏模式调整
  - 提供平衡的默认设置

- **与汉化模组的关系**：
  - 有对应的中文汉化版本"Random-Zombies-2-CN"
  - 由DXCHXX创作，使用大语言模型翻译

### Lingering Whispers... 余音缭绕

| 模组名称 | Workshop ID | 链接 | Mod ID | 版本 | 状态 |
|---------|------------|------|--------|------|------|
| Lingering Whispers... | 待补充 | [链接待补充] | LingeringWhispers | - | ✅ 兼容B42 |

**模组详情**

由Sebastian创作的音效增强模组，为游戏添加各种声音效果，增强游戏的沉浸感和恐怖氛围。

- **核心功能**：
  - 在游戏过程中添加各种声音效果
  - 增强游戏的沉浸感和恐怖氛围
  - 提供更多样的音频体验

- **音效特点**：
  - 群中的低语声
  - 门后传来的扭曲声音
  - 恳求灵魂的哀鸣
  - 指导或乞求的飘忽思绪
  - 以及更多种类的声音效果

- **设计理念**：
  - 通过声音增强游戏的沉浸感
  - 创造更加紧张和恐怖的游戏氛围
  - 增加玩家对环境的感知和警觉

- **使用体验**：
  - 在探索过程中突然听到各种声音
  - 增强夜晚和危险区域的紧张感
  - 可能会影响玩家的决策和行为
  - 与其他恐怖氛围增强模组配合使用效果更佳

### Workshop Update Checker 工作坊更新检查器

| 模组名称 | Workshop ID | 链接 | Mod ID | 版本 | 状态 |
|---------|------------|------|--------|------|------|
| Workshop Update Checker | 待补充 | [链接待补充] | WorkshopUpdateChecker | - | ✅ 兼容B42 |

**模组详情**

由Anach创作的模组管理工具，自动检查已安装的Steam工作坊模组是否有更新，并在游戏中通知玩家。

- **核心功能**：
  - 自动检查已安装的Workshop模组更新
  - 在游戏内通知玩家有新的模组版本
  - 轻量级设计，不影响游戏性能

- **管理优势**：
  - 减少手动检查模组更新的工作量
  - 确保玩家使用最新的模组版本
  - 避免因使用过时版本导致的兼容性问题
  - 支持玩家和服务器管理员

- **技术特点**：
  - 简单轻量，不影响游戏性能
  - 自动检测Steam下载的新版本
  - 在游戏内提供清晰的更新通知
  - 与Steam Workshop API集成

- **使用价值**：
  - 特别适合使用大量模组的玩家
  - 减少模组问题的排查时间
  - 确保多人游戏中的模组一致性
  - 支持模组生态系统健康发展
