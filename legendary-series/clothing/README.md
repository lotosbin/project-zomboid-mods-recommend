## 模组详情

### Legendary Cap (传说帽子)

- **类型**：服装/配饰类 - 帽子
- **防护属性**：
  - 脱落概率：0（不会脱落）
  - 保温：0.2
  - 防水：0.6
  - 抗风：0.8
- **材质系统**：
  - 粗糙(Rough)材质
  - 精制(Refined)材质
  - 传奇(Legendary)材质系统
- **颜色选项**：10种颜色（灰、绿、棕、黑、粉、橙、紫、蓝、红、白）
- **维护系统**：
  - 缝合针工具包维护
  - 皮革材质修复
- **获取方式**：
  - 在世界中发现
  - 通过杂志找到配方进行制作
  - 升级 Tailoring 技能自动解锁
- **文件大小**：6.974 MB
- **订阅量**：11,092

## 共同特性

所有服装/配饰类模组都有以下特点：

1. **材质系统**：三种材质等级（粗糙、精制、传说）
2. **防护属性**：提供不同程度的保温、防水和抗风效果
3. **沙盒定制**：可在沙盒模式中调整防护参数和掉落概率
4. **维护系统**：可使用缝合针和工具包进行修复
5. **多语言支持**：支持英语、西班牙语、德语、法语、俄语、韩语、泰语、中文等语言

## 安装与使用

1. 点击上表中的链接访问Steam创意工坊页面
2. 点击"Subscribe"(订阅)按钮
3. 启动Project Zomboid
4. 在模组列表中启用已订阅的服装模组
5. 开始游戏并在世界中寻找或制作这些传说装备

## 未来扩展

Akyrohunter曾表示如果用户对帽子模组反响良好，可能会考虑添加更多服装类物品，如：
- 牛仔帽版本
- 贝雷帽
- 其他帽子变体

用户可以在模组的评论区提出这些建议，以影响未来的开发方向。
