## 模组详情

### Legendary Naginata

- **类型**：武器类 - 长矛
- **特点**：高伤害、高耐久度的传说级长矛
- **颜色选项**：灰、绿、棕、粉、紫、蓝、红、橙、白、黑
- **获取方式**：
  - 在世界中发现
  - 通过杂志找到配方进行制作
  - 升级 MetalWelding 技能自动解锁
- **维护**：可使用磨刀石和焊枪修复和磨砺
- **研究**：可在武器上进行研究操作
- **文件大小**：5.611 MB
- **订阅量**：19,114

### Legendary Tactical Knife

- **类型**：武器类 - 战术刀
- **内容**：包含1把战术刀和11种刀鞘
- **特点**：更高耐久度和更低损坏概率
- **刀鞘颜色**：10种颜色可选（灰、绿、棕、粉、紫、蓝、红、橙、白、黑）
- **获取方式**：
  - 在世界中发现
  - 通过杂志找到配方进行制作
  - 升级 Tailoring 技能自动解锁
- **皮革战术刀鞘**：可找到和制作
- **文件大小**：13.339 MB
- **订阅量**：18,473

### Legendary Katana

- **类型**：武器类 - 武士刀
- **品质分级**：
  - 🔵 稀有(Rare)：比基础版本更高耐久度和更低损坏概率
  - 🟣 史诗(Epic)：比稀有版本更好耐久度和抗性
  - 🟠 传说(Legendary)：最佳伤害和耐久度
- **颜色选项**：10种颜色可选（灰、绿、棕、粉、紫、蓝、红、橙、白、黑）
- **刀鞘系统**：可找到和制作11种不同颜色的木质刀鞘
- **维护**：可使用磨刀石和焊枪修复和磨砺
- **获取方式**：
  - 在世界中发现三种品质的刀
  - 对应三种不同杂志学习制作配方
  - 升级 MetalWelding 技能自动解锁
- **兼容性**：与Tactical Sheaths B42模组兼容
- **文件大小**：5.570 MB
- **订阅量**：41,538

## 共同特性

所有武器类模组都有以下特点：

1. **维修系统**：可使用磨刀石和焊枪进行修复和磨砺
2. **研究功能**：可以在武器上进行研究操作
3. **沙盒定制**：可在沙盒模式中调整耐久度和损坏概率
4. **多语言支持**：支持英语、西班牙语、德语、法语、俄语、韩语、泰语、中文等语言

## 安装与使用

1. 点击上表中的链接访问Steam创意工坊页面
2. 点击"Subscribe"(订阅)按钮
3. 启动Project Zomboid
4. 在模组列表中启用已订阅的武器模组
5. 开始游戏并在世界中寻找或制作这些传说武器
