## 模组详情

### Legendary Satchel (传闻包)

- **容量**：基础游戏允许的最大容量49
- **特点**：
  - 最高重量减轻效果

  - 可与游戏原版背包同时装备（Build 42.13的新功能）
- **位置设置**：
  - 标准背包(BACK)和前包(FRONT)
- **材质系统**：
    - 粗糙(Rough)材质
    - 精制(Refined)材质

- **颜色选项**：5种颜色（灰、绿、棕、黑、粉）
- **维护系统**：
    - 缝合针工具包维护

- **获取方式**：

  - 通过杂志找到配方进行制作
  - 升级 Tailoring 技能自动解锁
- **文件大小**：5.789 MB
- **订阅量**：21,654

## 共同特性

所有背包和容器类模组都有以下特点：

1. **材质系统**：三种材质等级（粗糙、精制、传说）
2. **沙盒定制**：可在沙盒模式中调整容量、重量减轻和速度减少参数
3. **维护系统**：可使用缝合针和工具包进行修复
4. **多语言支持**：支持英语、西班牙语、德语、法语、俄语、韩语、泰语、中文等语言

## 安装与使用

1. 点击上表中的链接访问Steam创意工坊页面
2. 点击"Subscribe"(订阅)按钮
3. 启动Project Zomboid
4. 在模组列表中启用已订阅的背包模组
5. 开始游戏并在世界中寻找或制作这些传说背包

## 注意事项

- 在B42.13中，腰包可能存在装备后不显示在背包栏的问题，这是游戏的已知问题
- 所有背包模组都能与其他模组背包同时装备，提供更大的存储空间
- 背包的材质会随着使用而磨损，需要定期维护
