# 常识类模组

这些模组提供了使游戏体验更符合现实逻辑的改进和修复，通常被称为"常识"或"生活质量"类模组。

**原版模组详情**

由Rocco创作的完全 streamlined UI 布局模组，提供更简洁、更高效的库存管理体验。

- **功能**：
  - 将容器按钮移至左侧，使操作更自然，避免折叠时占用额外空间
  - 所有功能移至可折叠面板
  - "Transfer All"和"Take All"动作集成到容量显示框中
  - 用折叠图标替换物品图标，使组织更清晰
  - 重新设计所有UI纹理，采用极简边框和高透明度
  - 添加物品/类型名称自动截断功能，防止重叠
  - 调整文本颜色以提高可读性

- **高级功能**：
  - 容器重排序功能 - 直接拖动容器图标重新排列背包槽位
  - 搜索功能 - 在当前容器中搜索物品，匹配物品将移至顶部并高亮显示
  - 分类转移 - 可按类别/名称转移物品
  - 排序功能 - 按名称/重量/类型排序物品
  - 折叠/展开所有物品
  - 隐藏已装备物品

- **兼容性**：
  - 仅适用于Build 42，不兼容Build 41
  - 已编码更新以匹配B42.12.1
  - 与以下模组可能会有冲突（需要取消订阅）：
    - Reorder Containers（功能已集成）
    - Search Container（功能已集成）
    - Smart Stack（已有类似功能）
    - Auto Drop n' Loot（已有类似功能）
    - Bigger Inventory Container Icon（可能导致UI显示问题）

- **文件大小**：973.486 KB
- **订阅量**：174,928
- **收藏量**：8,658

## 实用工具类

### Read While Walking 行走中阅读

#### 原版模组

| 模组名称 | Workshop ID | 链接 | Mod ID | 版本 | 状态 |
|---------|------------|------|--------|------|------|
| Read While Walking | 2845952197 | [链接](https://steamcommunity.com/sharedfiles/filedetails/?id=2845952197) | SimpleReadWhileWalking | B41/B42 | ⚠️ B42.13有问题 |

**原版模组详情**

这是由star创作的经典模组，允许玩家在行走时阅读书籍，极大提高了游戏体验。

- **功能**：
  - 可以在行走时阅读书籍
  - 可在沙盒选项中设置阅读速度
  - 按下"R"键可开始/停止阅读（可配置）
  - 即使书籍在附近容器中也可以开始阅读（会自动取出）
  - 优先级系统：收藏书籍 > 未读完书籍 > 背包书籍 > 背包内容器 > 外部容器

- **阅读限制和效果**：
  - 阅读时会启用"探索雾气"效果，降低视野范围
  - 可在沙盒选项中调整雾气黑暗程度
  - 无法在搜索模式下阅读
  - 疲劳程度会影响阅读时的视野范围

- **兼容性**：
  - 与游戏未来更新兼容（包括Build 42+）
  - 与大多数模组兼容
  - 支持多人游戏
  - 可安全启用/禁用

- **文件大小**：94.714 KB
- **订阅量**：876,589
- **收藏量**：21,495

## 食物和储藏

### [B42.13] Fruits in jars 水果罐头

| 模组名称 | Workshop ID | 链接 | Mod ID | 版本 | 状态 |
|---------|------------|------|--------|------|------|
| [B42.13] Fruits in jars | 3432006285 | [链接](https://steamcommunity.com/sharedfiles/filedetails/?id=3432006285) | Makefruitinjar | B42.13 | ✅ 兼容B42.13 |

**模组详情**

由Bender创作的水果罐头模组，允许玩家将不同类型的水果制作成罐头，以便长期保存。这是一个非常实用的常识类模组，符合现实中保存水果的逻辑。

- **功能**：
  - 可以将多种水果制作成罐头，保存其风味一整年
  - 不同水果需要不同数量制作罐头：
    - 1x：芒果、菠萝、西瓜
    - 2x：梨、苹果
    - 3x：香蕉、柠檬、青柠、橙子、桃子
    - 4x：浆果
    - 5x：樱桃
  - 制作罐头盖：需要5级锻造技能和相关配方
    - 需要材料：球头锤、钳子、金属凿、煤炭和小金属板

- **兼容性**：
  - 专为Build 42.13.0版本设计
  - 未在多人模式下测试
  - 支持法语/英语翻译

- **文件大小**：486.735 KB
- **订阅量**：39,088
- **收藏量**：1,410

- **注意事项**：
  - 西瓜罐头可能存在一个bug：无论烹饪状态如何，打开后都可能是陈腐的罐头
  - 作者计划在未来更新中添加缺失的水果种类
  - 罐头可作为烹饪食谱中的水果原料

## 常识类模组特点

这类模组通常具有以下特点：

1. **提高真实感**：使游戏机制更符合现实逻辑
2. **修复不合理设计**：改进游戏中不合理的限制或设定
3. **生活质量提升**：简化繁琐操作，提高游戏体验
4. **轻量级**：通常不会对游戏性能产生显著影响
5. **兼容性好**：通常与大多数其他模组兼容

## 模组使用指南

### Read While Walking (原版 + 补丁)

1. 订阅原版"Read While Walking"模组 (ID: 2845952197)
2. 订阅B42.13兼容性补丁 (ID: 3625232801)
3. 启动Project Zomboid
4. 在模组列表中启用这两个模组（补丁应加载在原版之后）
5. 在游戏中设置阅读速度（沙盒选项中调整）
6. 开始游戏并享受无错误的行走阅读体验

### CleanUI 界面优化（原版）

1. 订阅原版"[B42]CleanUI V2.2"模组 (ID: 3437629766)
2. 启动Project Zomboid
3. 在模组列表中启用该模组
4. 根据个人需求，使用ModOptions界面调整CleanUI设置

**注意**: B42.13兼容性补丁当前会导致游戏崩溃，建议等待作者更新后再使用补丁。

### Fruits in jars 水果罐头

1. 订阅"[B42.13] Fruits in jars"模组 (ID: 3432006285)
2. 启动Project Zomboid
3. 在模组列表中启用该模组
4. 在游戏中收集水果并找到或制作罐子和盖子
5. 使用烹饪技能将水果制作成罐头，享受长期保存的美味
