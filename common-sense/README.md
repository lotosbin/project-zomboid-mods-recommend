# 常识类模组

这些模组提供了使游戏体验更符合现实逻辑的改进和修复，通常被称为"常识"或"生活质量"类模组。

## 常识类模组特点

这类模组通常具有以下特点：

1. **提高真实感**：使游戏机制更符合现实逻辑
2. **修复不合理设计**：改进游戏中不合理的限制或设定
3. **生活质量提升**：简化繁琐操作，提高游戏体验
4. **轻量级**：通常不会对游戏性能产生显著影响
5. **兼容性好**：通常与大多数其他模组兼容

## 实用工具类

### Conditional-Speech 条件语音

| 模组名称 | Workshop ID | 链接 | Mod ID | 版本 | 状态 |
|---------|------------|------|--------|------|------|
| Conditional-Speech | 2398253681 | [链接](https://steamcommunity.com/sharedfiles/filedetails/?id=2398253681) | Conditional-Speech | - | ⚠️ B42.13有问题 |

**模组详情**

由Chuckleberry Finn创作的条件语音模组，根据角色状态和情绪生成动态对话，大大增强游戏沉浸感。

- **功能**：
  - 根据多种条件和随机化生成动态对话
  - 包含所有状态提示语(moodles)和某些事件的标准短语
  - 可在菜单中切换所有语音
  - 根据状态提示对聊天应用动态过滤
  - 醉酒、惊吓或疼痛时可能导致大喊或不清晰的言语
  - 游戏通过灰化语音来模拟音量大小
  - 可在游戏菜单的"多人游戏"部分更改语音颜色

- **定制选项**：
  - 所有短语都可以在菜单中开启或关闭
  - 支持沙盒选项控制
  - 多种语言支持（中文、英语、法语、韩语、波兰语、葡萄牙语(巴西)、俄语、西班牙语、土耳其语、泰语、日语、乌克兰语、意大利语等）

- **兼容性**：
  - 兼容Build 41和Build 42（但最新版B42.13存在问题）
  - 支持多人游戏
  - 需要以下前置模组：
    - Easy Config
    - Chuckederrors
    - Magnifier
    - Mod Update and Alert System

- **文件大小**：1.451 MB
- **订阅量**：290,643
- **收藏量**：12,431

- **注意**：
  - B42.13版本可能出现错误，作者表示会尽快更新
  - 女性角色的语音可能听起来较为男性化，影响沉浸感（作者计划改进）
  - 中文翻译仅提供简体中文（在B41版本中有用户报告中文语言功能无法正常工作）

### Read While Walking 行走中阅读

#### 原版模组

| 模组名称 | Workshop ID | 链接 | Mod ID | 版本 | 状态 |
|---------|------------|------|--------|------|------|
| Read While Walking | 2845952197 | [链接](https://steamcommunity.com/sharedfiles/filedetails/?id=2845952197) | SimpleReadWhileWalking | B41/B42 | ⚠️ B42.13有问题 |

**原版模组详情**

这是由star创作的经典模组，允许玩家在行走时阅读书籍，极大提高了游戏体验。

- **功能**：
  - 可以在行走时阅读书籍
  - 可在沙盒选项中设置阅读速度
  - 按下"R"键可开始/停止阅读（可配置）
  - 即使书籍在附近容器中也可以开始阅读（会自动取出）
  - 优先级系统：收藏书籍 > 未读完书籍 > 背包书籍 > 背包内容器 > 外部容器

- **阅读限制和效果**：
  - 阅读时会启用"探索雾气"效果，降低视野范围
  - 可在沙盒选项中调整雾气黑暗程度
  - 无法在搜索模式下阅读
  - 疲劳程度会影响阅读时的视野范围

- **兼容性**：
  - 与游戏未来更新兼容（包括Build 42+）
  - 与大多数模组兼容
  - 支持多人游戏
  - 可安全启用/禁用

- **文件大小**：94.714 KB
- **订阅量**：876,589
- **收藏量**：21,495

## 时间管理类

### Fast Forward (MP) - Build 42 快进时间

| 模组名称 | Workshop ID | 链接 | Mod ID | 版本 | 状态 |
|---------|------------|------|--------|------|------|
| Fast Forward (MP) - Build 42 | 3623959321 | [链接](https://steamcommunity.com/sharedfiles/filedetails/?id=3623959321) | FastForwardMP_B42 | Build 42 | ✅ 兼容B42.13 |

**原版模组参考**：
[Fast Forward (MP)](https://steamcommunity.com/sharedfiles/filedetails/?id=2968318536) (不再维护的Build 41版本)

**模组详情**

由ardernord更新的多人游戏时间快进模组，允许在多人游戏中暂停和加快时间流逝，大大提高长期活动的效率，是多人服务器必备的常识类质量提升工具。

- **功能**：
  - 在多人游戏中暂停和控制时间流速
  - 所有玩家必须选择相同的时间速度才能生效
  - 添加强制按钮，管理员可强制所有玩家使用选定速度（默认仅管理员可用）
  - 当速度设置为0时，游戏会暂停（但UI交互受限）

- **多人同步机制**：
  - 所有玩家必须选择相同的时间速度
  - 当玩家移动时，时间速度会自动恢复为正常速度
  - 强制功能仅在玩家挂机(AFK)时有效

- **技术改进**：
  - 修复了原版模组在Build 42中的兼容性问题
  - 添加了反作弊保护类型23的空检查，避免错误
  - 即使无法禁用反作弊保护，模组仍可继续运行

- **兼容性**：
  - 专为Build 42多人游戏设计
  - 与大多数模组兼容
  - 主要适用于合作模式游戏（作者表示主要用于合作游戏，对反作弊不重视）

- **文件大小**：263.974 KB
- **订阅量**：462
- **收藏量**：23

- **注意事项**：
  - 原版作者已不再维护Build 41版本
  - 定时操作（如移动物品、砍树、制作）可能无法完全加速（服务器端验证的操作）
  - 停止时间（速度设为0）时UI交互会受限，界面可能看起来冻结
  - 玩家中立或移动状态会导致时间速度恢复正常

### [B42.13] Fruits in jars 水果罐头

| 模组名称 | Workshop ID | 链接 | Mod ID | 版本 | 状态 |
|---------|------------|------|--------|------|------|
| [B42.13] Fruits in jars | 3432006285 | [链接](https://steamcommunity.com/sharedfiles/filedetails/?id=3432006285) | Makefruitinjar | B42.13 | ✅ 兼容B42.13 |

**模组详情**

由Bender创作的水果罐头模组，允许玩家将不同类型的水果制作成罐头，以便长期保存。这是一个非常实用的常识类模组，符合现实中保存水果的逻辑。

- **功能**：
  - 可以将多种水果制作成罐头，保存其风味一整年
  - 不同水果需要不同数量制作罐头：
    - 1x：芒果、菠萝、西瓜
    - 2x：梨、苹果
    - 3x：香蕉、柠檬、青柠、橙子、桃子
    - 4x：浆果
    - 5x：樱桃
  - 制作罐头盖：需要5级锻造技能和相关配方
    - 需要材料：球头锤、钳子、金属凿、煤炭和小金属板

- **兼容性**：
  - 专为Build 42.13.0版本设计
  - 未在多人模式下测试
  - 支持法语/英语翻译

- **文件大小**：486.735 KB
- **订阅量**：39,088
- **收藏量**：1,410

- **注意事项**：
  - 西瓜罐头可能存在一个bug：无论烹饪状态如何，打开后都可能是陈腐的罐头
  - 作者计划在未来更新中添加缺失的水果种类
  - 罐头可作为烹饪食谱中的水果原料

## 模组使用指南

### Read While Walking (原版 + 补丁)

1. 订阅原版"Read While Walking"模组 (ID: 2845952197)
2. 订阅B42.13兼容性补丁 (ID: 3625232801)
3. 启动Project Zomboid
4. 在模组列表中启用这两个模组（补丁应加载在原版之后）
5. 在游戏中设置阅读速度（沙盒选项中调整）
6. 开始游戏并享受无错误的行走阅读体验

### Fast Forward (MP) - Build 42

1. 订阅原版"[B42]CleanUI V2.2"模组 (ID: 3437629766)
2. 启动Project Zomboid
3. 在模组列表中启用该模组
4. 在游戏中设置时间流动（可通过管理员菜单或设置）
5. 确保所有玩家都选择相同的时间速度以同步时间

### Fruits in jars 水果罐头

1. 订阅"[B42.13] Fruits in jars"模组 (ID: 3432006285)
2. 启动Project Zomboid
3. 在模组列表中启用该模组
4. 在游戏中收集水果并找到或制作罐子和盖子
5. 使用烹饪技能将水果制作成罐头，享受长期保存的美味

### Conditional-Speech 条件语音

1. 订阅"Conditional-Speech"模组 (ID: 2398253681)
2. 确保已订阅所有必需的前置模组
3. 启动Project Zomboid
4. 在模组列表中启用这些模组
5. 在游戏中根据需要通过菜单调整语音设置
