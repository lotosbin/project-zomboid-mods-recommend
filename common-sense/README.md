# 常识类模组

这些模组提供了使游戏体验更符合现实逻辑的改进和修复，通常被称为"常识"或"生活质量"类模组。

## 实用工具类

### Read While Walking 行走中阅读

#### 原版模组

| 模组名称 | Workshop ID | 链接 | Mod ID | 版本 | 状态 |
|---------|------------|------|--------|------|------|
| Read While Walking | 2845952197 | [链接](https://steamcommunity.com/sharedfiles/filedetails/?id=2845952197) | SimpleReadWhileWalking | B41/B42 | ⚠️ B42.13有问题 |

**原版模组详情**

这是由star创作的经典模组，允许玩家在行走时阅读书籍，极大提高了游戏体验。

- **功能**：
  - 可以在行走时阅读书籍
  - 可在沙盒选项中设置阅读速度
  - 按下"R"键可开始/停止阅读（可配置）
  - 即使书籍在附近容器中也可以开始阅读（会自动取出）
  - 优先级系统：收藏书籍 > 未读完书籍 > 背包书籍 > 背包内容器 > 外部容器

- **阅读限制和效果**：
  - 阅读时会启用"探索雾气"效果，降低视野范围
  - 可在沙盒选项中调整雾气黑暗程度
  - 无法在搜索模式下阅读
  - 疲劳程度会影响阅读时的视野范围

- **兼容性**：
  - 与游戏未来更新兼容（包括Build 42+）
  - 与大多数模组兼容
  - 支持多人游戏
  - 可安全启用/禁用

- **文件大小**：94.714 KB
- **订阅量**：876,589
- **收藏量**：21,495

#### B42.13兼容性补丁

| 模组名称 | Workshop ID | 链接 | 版本 | 状态 |
|---------|------------|------|------|------|
| Simple Read While Walking 42.13+ compatibility patch | 3625232801 | [链接](https://steamcommunity.com/sharedfiles/filedetails/?id=3625232801) | - | - | ✅ 兼容B42.13 |

**补丁详情**

这是一个小型修复模组，由pimat.studio创作，用于解决原版"Read While Walking"模组在B42.13更新后出现的错误问题。

- **功能**：恢复在行走时阅读书籍的能力，无错误信息
- **兼容性**：专为Build 42.13+设计，修复原版模组的错误
- **注意**：主要针对单人模式修复，多人模式兼容性未测试
- **大小**：156.309 KB（轻量级）
- **依赖**：需要原版"Read While Walking"模组

## 常识类模组特点

这类模组通常具有以下特点：

1. **提高真实感**：使游戏机制更符合现实逻辑
2. **修复不合理设计**：改进游戏中不合理的限制或设定
3. **生活质量提升**：简化繁琐操作，提高游戏体验
4. **轻量级**：通常不会对游戏性能产生显著影响
5. **兼容性好**：通常与大多数其他模组兼容

## 模组使用指南

### Read While Walking (原版 + 补丁)

1. 订阅原版"Read While Walking"模组 (ID: 2845952197)
2. 订阅B42.13兼容性补丁 (ID: 3625232801)
3. 启动Project Zomboid
4. 在模组列表中启用这两个模组（补丁应加载在原版之后）
5. 在游戏中设置阅读速度（沙盒选项中调整）
6. 开始游戏并享受无错误的行走阅读体验
